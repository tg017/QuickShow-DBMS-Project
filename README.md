# QuickShow – Online Movie Ticket Booking & Theatre Management System

**DBMS Course Project**

QuickShow is a web-based movie ticket booking and theatre management system built for a cinema chain client (Galaxy Cinemas). It replaces manual booking with an online platform where customers can browse movies, check showtimes, select seats, and book tickets, while admins manage movies, theatres, screens, and shows.

## Status
🚧 Project in early stages — requirement specification and ER/database design completed. Implementation in progress.

## Tech Stack
- **Backend:** Spring Boot
- **Database:** MySQL
- **Frontend:** Thymeleaf

## Core Features (Planned)
- Customer registration & login
- Browse, search, and filter movies (by language, genre, certificate)
- View showtimes across theatres
- Seat selection and ticket booking/cancellation
- Real-time seat availability (no double booking)
- Admin management of movies, theatres, screens, shows, and bookings
- Payment tracking

## Entities
Customer, Movie, Theatre, Screen, Seat, Show, Booking, Payment, Admin
